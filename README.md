# Legacy Mouse Tweaks Ornithe
A mod that enhances inventory management by adding various functions to the mouse buttons. A 1.8.9 Ornithe Port of YaLTeR's [original mod](https://modrinth.com/mod/mouse-tweaks). Note the scroll wheel tweak is disabled by default as it may be considered cheating on PvP servers.

# Compatibility
Mouse Tweaks should work with everything based on `InventoryMenuScreen`. There is currently no API planned for other containers, but PRs are welcome.
